重装系统PE工具

PE工具官网大部分都带有详细的重装系统教程，按照步骤来即可，非常方便。

微PE 微PE体积小，无捆绑、非常纯净，集成了必备的工具。
优启通/IT天空 EasyU为IT天空论坛出品的经典软件，曾经的版本有捆绑行为，目前官方原版为纯净无捆绑的版本。
firpe 纯净无捆绑，集成了Win10PE、03PE（来自USBOS），对新老电脑的兼容性佳，体积适中
EasyRCV 任何 Windows 系统下一键重装 Windows 系统
USBOS USBOS也是纯净无捆绑的PE，@chiannet的作品。集成多个内核PE，对新旧电脑的兼容性好。
Edgeless 纯净无捆绑，采用了较新的内核。是一款比较特殊的PE，它的特色功能时自由定制，比如强大的插件，可以自行定制壁纸/图标/主题、自由添加装机工具、驱动、库文件等等，

参考链接：https://mp.weixin.qq.com/s/07Q4hTGFcIiWBdqz_o4zig

其他：冰封U盘启动工具、软碟通（UltraISO）、老毛桃大白菜等有捆绑不推荐
