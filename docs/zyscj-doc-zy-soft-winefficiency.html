🔗Windows效率工具

来源：https://zyscj.com/zy/soft/winefficiency.html · 抓取时间：2026-11-01 · 外链 56 个

快速启动与搜索

Everything 最快速的文件/文件夹搜索工具
Listary 老牌设计独到的搜索工具（推荐，个人日常使用）
Quicker 快速启动，集成大量功能性插件,文字识别、截图、重命名等

其他：uTools、Wox、Maya、Lucy、Lily、RunAny、nTrun

文档内文字搜索

Archivarius 3000 唯一默认支持azw3／epub／mobi／md等格式文档，支持预览，速度快
Filelocator Pro 支持无索引搜索，不支持自动更新索引，适合使用频率不高的用户
DocFetcher 开源免费、支持win、mac、Linux

其他：AnyTXT Searcher、win10自带搜索，参考此文>>

多选项卡标签

Win11已自带资源管理器选项卡

QTTabBar 通过标签和额外的文件夹视图扩展Windows资源管理器
360文件夹 360出品，使用过程中未发现广告，体验不错
Stardock Groupby 通过标签和额外的文件夹视图扩展所有Windows软件
clover 为Windows资源管理器资源管理器加上标签

Windows管理器

Total Commander Windows 最佳文件管理，上手较困难-中文增强版
XYplorer 多标签文件管理器，比TC要简单好上手-绿色版
Q-Dir 免费、独到的四屏比对的高级文件管理器

其他：FreeCommander、Double Commander、Multi Commander

文件快速预览

QuickLook 界面好看，设置项简单，WUP格式的安装和卸载方便。
Seer 界面好看，设置项丰富，插件下载方便，查看速度一般
Wlx2Explorer 从著名的Total Commander中衍生出来的，可以完全利用TC插件，速度最快，但设置项少

鼠标手势

WGestures 定义鼠标完成Windows 全局手势
crxMouse Chrome™ 手势 chrome手势操作、完成复制、标签关闭、前进后退等操作

剪切板

Ditto 剪切板增强复制与管理
快贴 跨平台系统剪贴板同步工具

桌面整理

Fences 自动整理桌面快捷方式和图标栅栏
腾讯桌面整理 免费、支持桌面整理、全局搜索等功能，请下载独立版
Desktopcal 简洁美观的Windows 桌面日历，用做备忘

远程控制

SAKURA FRP FRP内网穿透，可以直接用Windows自带的远程，免费10 Mibps速度，无限签到领流量
向日葵 有个人免费版，速度尚可，付费性价比高，推荐日常使用
ToDesk 目前个人免费，仅Windows客户端，速度不错。
TeamViewer 速度不错，功能强大，现在基本都需付费使用，价格偏高

其他：AnyDesk、WanGooe、Splashtop、网络人、微软Windows远程桌面(自带)、QQ远程

文件对比

Beyond Compare 可配合Total Commander使用，支持文件格式全，收费。
WinMerge 免费开源软件，支持Word、Excel、TXT等格式的文件

其他：Meld、KDiff3

磁盘文件大小查看

SpaceSniffer 查看文件夹和文件在磁盘上的结构
WizTree 直观地查看所有文件和文件夹的大小

重复文件查找

Duplicate Cleaner 收费，同类网上推荐比较多-绿色注册版
dupeGuru 免费开源软件，体验也很不错

其他：Fast Duplicate File Finder、Clone Files Checker
