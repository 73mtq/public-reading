实战项目路线：从零基础到能碰论文

  • 适用对象：CV 方向的研究生新生，没有科研经历，需要一条把课程知识变成作品的路线。
  • 复核日期：2026-09-28（GitHub 仓库数据取自 api.github.com，B 站条目数据取自 api.bilibili.com）。
  • 相关篇目：分周安排与先后顺序见 《起步路线》；读论文的方法见 《论文精读方法》。

〇、最小前置知识链（做项目前必须打通的三级台阶）

总耗时预估：3~5周（与第一个入门项目可并行推进）

阶段 内容 推荐资源（全部免费） 预计耗时
① Python 编程 基础语法、函数/类、NumPy 数组操作、Matplotlib 画图 • CS231n 官方 Python/Numpy 教程（含 Jupyter/Colab，专门为 CV 课程设计）：https://cs231n.github.io/python-numpy-tutorial/
• 廖雪峰 Python 教程（中文）：https://liaoxuefeng.com/books/python/introduction/		 1~2 周
② PyTorch 框架 Tensor 操作、自动求导、nn.Module、DataLoader、训练循环 • B站《PyTorch深度学习快速入门教程【小土堆】》（约19.8万粉，中文圈公认最友好入门，配套 GitHub 开源代码库）：https://www.bilibili.com/video/BV1hE411t7RN
• PyTorch 官方《60分钟闪电战》：https://docs.pytorch.org/tutorials/beginner/deep_learning_60min_blitz.html
• Datawhale《深入浅出PyTorch》开源教程（基础/进阶/拓展三模块，可参加免费组队学习，约14天周期）：https://github.com/datawhalechina/thorough-pytorch		 2 周
③ CNN 基础理论 卷积/池化/感受野、经典架构（LeNet→AlexNet→VGG→ResNet）、损失函数与反向传播 • 《动手学深度学习》PyTorch版 中文在线教材（李沐等著，第6章CNN、第7章现代CNN、第13章计算机视觉，代码+数学+HTML三位一体，可跑 Jupyter）：https://zh.d2l.ai/ （B站配套视频"跟李沐学AI"）
• 斯坦福 CS231n 课程笔记（Spring 2026 作业仍持续更新，业界公认的 CV 圣经课）：https://cs231n.github.io/		 1~2 周（可贯穿项目全程）

💡 衔接建议：学完①即可开始"入门档项目1"；②③与入门档项目并行，遇到概念不懂再回头补，不要等"全部学完"才动手——这是零基础者最常见的打转方式。

一、入门档（第1~2个月）：跑通第一个"能看的见结果"的模型

项目1：MNIST 手写数字识别 —— CV 界的 "Hello World"

维度 内容
项目内容 训练一个 CNN 识别 28×28 手写数字（0-9），走完"数据加载→建模→训练→测试→预测可视化"的完整流程
使用的工具 Python + PyTorch（torchvision 内置数据集，几行代码自动下载）
数据集 MNIST（6万训练+1万测试， torchvision.datasets 一行加载，无需手动下载）
预计耗时 2~3 天（含环境搭建；纯写代码半天）
学习价值 建立完整训练 pipeline 的肌肉记忆；理解 epoch/loss/accuracy 的直观含义；调试成功后的正反馈极强
教程链接 • 《动手学深度学习》5.5节 CNN 实战（含完整可运行代码）：https://zh.d2l.ai/chapter_cnn/lenet.html
• Datawhale《动手学CV-PyTorch》1.5节"初识图像分类:MNIST分类实战"：https://github.com/datawhalechina/dive-into-cv-pytorch
验收标准 测试集准确率 ≥ 98%；能向别人解释每一行代码在做什么

项目2：CIFAR-10 图像分类（自建 CNN + ResNet 迁移学习对比）

维度 内容
项目内容 ①自己搭一个简单 CNN（如 VGG 风格）在 CIFAR-10 上训练；②加载 torchvision 预训练 ResNet18 微调，对比两者精度与训练曲线
使用的工具 PyTorch + torchvision + TensorBoard（学会看训练曲线）
数据集 CIFAR-10（5万张 32×32 彩色图，10类，torchvision 自动下载）
预计耗时 3~5 天
学习价值 亲历"深度网络 > 浅层网络"与"迁移学习 > 从零训练"两个核心规律；掌握微调（fine-tuning）这一科研高频操作；学会用 TensorBoard 诊断过拟合
教程链接 • PyTorch 官方教程《Training a Classifier》（用 CIFAR-10 讲完整分类流程，官方权威）：https://docs.pytorch.org/tutorials/beginner/blitz/cifar10_tutorial.html
• 《动手学深度学习》第7章"现代卷积神经网络"（含 ResNet 从零实现）：https://zh.d2l.ai/chapter_convolutional-modern/index.html
验收标准 自建 CNN 达到 ~75%+；ResNet18 微调达到 ~90%+；能画出两者的 loss 曲线并解释差异

项目3：OpenCV 图像处理小工具箱（传统视觉打底，1周内可见成品）

维度 内容
项目内容 做一个含 5~6 个功能的"图片处理小工具"：灰度化/滤波去噪/Canny 边缘检测/轮廓提取与计数/Haar 级联人脸检测/简单视频流实时处理
使用的工具 Python + OpenCV（pip install opencv-python）+ （可选）tkinter 做个简单 GUI
数据集 自拍照片或任意本地图片即可；Haar 级联分类器随 OpenCV 自带
预计耗时 5~7 天
学习价值 理解"像素/通道/卷积核"这些深度学习的物理底层；Haar 人脸检测是了解传统方法与深度方法差异的最佳对照（为读懂检测类论文打基础）；成品可直接放简历/展示
教程链接 • OpenCV 官方 Python 教程（免费在线）：https://docs.opencv.org/4.x/d6/d00/tutorial_py_root.html
• 腾讯云《零基础学OpenCV+Python图像处理：手把手带你做人脸识别》（含环境搭建到人脸检测完整代码）：https://cloud.tencent.com/developer/article/2405198
验收标准 摄像头实时人脸框检测跑通；能用 Canny + 轮廓完成"数硬币/数螺丝"这类计数任务

📌 入门档小结：三个项目共约 3~4 周，完成后应具备：完整训练流程经验 + 迁移学习经验 + 传统视觉直觉。入门档还不需要 GPU：MNIST/CIFAR-10 用 CPU 或 Kaggle 免费 GPU（每周 30 小时）足够。

二、进阶档（第2~4个月）：选定方向，做一个"有工程量"的系统

项目4：YOLO 目标检测：从预训练推理到自定义数据集训练

维度 内容
项目内容 ①用官方预训练模型对自己拍的照片/视频做检测（一行命令）；②自己拍摄 100~300 张图（如口罩、安全帽、水果），用 labelImg 或 Roboflow 标注，训练自己的检测模型
使用的工具 Ultralytics YOLO（pip install -U ultralytics，Python≥3.8；提供 CLI 和 Python API 两种用法）；标注工具 labelImg / Roboflow
数据集 自建小数据集（100~300 张标注图）；官方教程演示用 Roboflow 的公开数据集（如热狗检测），无需自建也可完成教学流程
预计耗时 1~2 周
学习价值 目标检测是工业界 CV 需求量第一的任务；完整体验"采集→标注→训练→部署"的数据流程，这正是科研中"构建自己的 benchmark"的雏形；Ultralytics 官方文档完善（2026-09-28 读取：ultralytics/ultralytics 62,058 stars，ultralytics/yolov5 58,088 stars）
教程链接 • Ultralytics 官方 Quickstart（含一行命令推理示例，2026-09-28 实测可访问）：https://docs.ultralytics.com/quickstart/
• YOLOv5 自定义数据训练教程（官方已归入「YOLOv5 (Legacy)」分类，2026-09-28 实测可访问）：https://docs.ultralytics.com/yolov5/tutorials/train-custom-data/
• B站《目标检测 YOLOv5 开源代码项目调试与讲解实战【土堆 x 布尔艺数】》（10 集，UP主"我是土堆"，2026-09-28 实测播放 77.5 万）：https://www.bilibili.com/video/BV1tf4y1t7ru （av291272406）
• B站《PyTorch 目标检测实战系列教程-入门篇【土堆教程】》（2025-07 起更新，32 集，讲到 VOC/COCO/YOLO 三种标注格式与自建数据集）：https://www.bilibili.com/video/BV19Z31z8ENH/
验收标准 mAP50 明显高于随机水平；能在自己的新照片上稳定检测自定义类别；理解 YOLO 输出的 bbox/置信度/类别是什么

项目5：U-Net 图像语义分割（医学/遥感场景）

维度 内容
项目内容 用 U-Net 完成像素级二分类分割（如细胞/病灶/遥感建筑），理解编码器-解码器与跳跃连接
使用的工具 PyTorch +（可选） segmentation-models-pytorch 库（一行加载带预训练骨干的 U-Net）
数据集 • Carvana 汽车抠图（milesial/Pytorch-UNet 官方教程数据，4998张+标注，一键下载脚本）
• 或 Kaggle Data Science Bowl 2018 细胞核分割（公开，含顶级方案分享）
• 或天池地表建筑物识别（Datawhale 配套开源教程，见链接）
预计耗时 1~2 周
学习价值 分割是 CV 三大任务之一，U-Net 是医学影像方向引用量最高的架构（导师的论文很可能用到）；学会 Dice/IoU 评测指标；跳跃连接思想可迁移到一切 encoder-decoder 结构
教程链接 • milesial/Pytorch-UNet（GitHub 官方实现，11,680 stars，2026-09-28 读取；README 即教程，含 Carvana 数据集下载脚本）：https://github.com/milesial/Pytorch-UNet
• Datawhale《计算机视觉实践（地表建筑物识别）》（天池赛题配套开源教程，仓库最后推送 2024-08-12）：https://github.com/datawhalechina/team-learning-cv
• 《动手学深度学习》第 13 章计算机视觉（含语义分割与转置卷积原理）：https://zh.d2l.ai/chapter_computer-vision/index.html
验收标准 在验证集上 Dice ≥ 0.85（视数据集）；能可视化分割 mask 与原图叠加效果

项目6：PaddleOCR 文字识别系统（中文场景友好，成品感最强）

维度 内容
项目内容 搭建"拍照/截图→检测文字→识别文字"的完整 OCR 小系统，可对自己的证件/书本/路牌照片批量识别导出
使用的工具 PaddlePaddle + PaddleOCR（PP-OCRv5/v6 系列，支持100+语言；提供极简 Python API）
数据集 无需训练数据（直接用官方预训练模型）；进阶可微调自建场景文字数据
预计耗时 2~3 天（跑通）~1周（封装成小工具）
学习价值 OCR 是实用性最强的 CV 应用之一；体验"两个模型串联的系统"（检测+识别）；国产框架中文文档零障碍；遇到文档类论文（PDF图表提取）时能自己造轮子
教程链接 • PaddleOCR GitHub（90,320 stars，最后推送 2026-09-16，README 有 5 分钟快速上手）：https://github.com/PaddlePaddle/PaddleOCR
• PaddleOCR 官方文档（含 PP-OCRv5 快速体验）：https://www.paddleocr.ai/latest/version3.x/quick_start.html
验收标准 对清晰印刷体照片识别准确率目测 > 90%；理解 DBNet（检测）+ CRNN/SVTR（识别）的串联逻辑

项目7（可选，人脸方向）：人脸检测与识别小系统

维度 内容
项目内容 用 face_recognition 库（封装了 dlib 的人脸识别）实现"录入几张同班同学照片→摄像头实时识别是谁"，并了解其背后的 FaceNet 嵌入思想
使用的工具 Python + face_recognition（号称"世界上最简单的人脸识别 API"）+ OpenCV 摄像头流
数据集 自拍照片库（每人5~10张即可）；进阶可玩 LFW 公开数据集
预计耗时 4~6 天
学习价值 人脸识别是 CV 最经典应用；理解"嵌入向量+距离度量"范式（对比学习雏形，CLIP等前沿工作同源思想）；体验调用工业级预训练模型的威力
教程链接 • ageitgey/face_recognition GitHub（56,784 stars，最后推送 2026-06-25；含完整示例代码，Windows/Mac/Linux 安装指引）：https://github.com/ageitgey/face_recognition
• 雷锋网《最适合初学者的18个经典开源计算机视觉项目》人脸识别章节（介绍了 LFW/MegaFace 数据集与 FaceNet/DeepFace 技术脉络）：https://www.leiphone.com/category/yanxishe/bUbJNFYR79c3VM5Q.html
验收标准 实时视频流中正确标注出"是谁"；能解释 128 维特征向量的含义

📌 进阶档选型建议：不必全做。检测（项目4）+ 分割（项目5） 是与科研衔接最紧密的两条主线（覆盖顶会论文大半任务类型）；OCR/人脸按兴趣二选一。此阶段强烈建议用 Kaggle/Colab 免费 GPU 或实验室服务器。

三、科研衔接档（第4~6个月）：从"会用模型"到"能碰论文"

项目8：Kaggle 入门赛（Digit Recognizer / Dogs vs Cats）

维度 内容
项目内容 完整参加一场 Kaggle Getting Started 竞赛：下载→本地/Kaggle Notebook 训练→提交→看排行榜→读高分公开 Notebook 学 trick
使用的工具 PyTorch/Keras 均可 + Kaggle Notebook（免费 GPU P100/T4，每周约30h）
数据集 • Digit Recognizer（MNIST 赛道，官方定位"you're new to computer vision"的完美第一赛，长期开放滚动榜单——2026年9月核实状态 ONGOING）：https://www.kaggle.com/competitions/digit-recognizer
• Dogs vs. Cats（经典猫狗分类）：https://www.kaggle.com/c/dogs-vs-cats
预计耗时 2~4 周
学习价值 学习"排行榜思维"（同样数据，数据增强/模型融合/TTA 能提多少分）；读别人的公开 Notebook 是最高效的偷师方式；Kaggle 成绩是简历上可量化的能力证明
教程链接 • Kaggle 官方 Learn 免费微课程（Intro to Deep Learning / Computer Vision）：https://www.kaggle.com/learn
• 天池新人赛（国内版 Kaggle，"零基础入门CV-街景字符编码识别"，配套 Datawhale 五大 Task 完整开源教程：赛题理解→数据扩增→字符识别模型→训练验证→模型集成，15天周期）：https://tianchi.aliyun.com/competition/entrance/531795/information 与 https://github.com/datawhalechina/team-learning-cv
验收标准 提交成绩进入前 50%；至少精读 3 份高分公开 Notebook 并复现其中 1 个 trick

项目9：复现一篇经典论文（LeNet→AlexNet→ResNet→迷尼 ViT 任选其一）

维度 内容
项目内容 不看现成代码，仅凭论文+公式，从零实现模型并在数据集上训练出接近论文的精度；对照官方/高星开源实现复盘差异
使用的工具 PyTorch + torchvision 数据集（ImageNet 子集/CIFAR-100/Imagenette）
数据集 CIFAR-10/100、Imagenette（ImageNet 10类子集，可直接下载）、ImageNet-1k（需注册申请，量大慎入）
预计耗时 2~4 周/篇（建议先 ResNet，再迷尼 ViT）
学习价值 这是与导师"论文精读汇报"任务直接对口的训练：复现过的论文，汇报时能讲出"作者没写的坑"；从零实现 ViT 后再读 Swin/MAE/CLIP 会全程无障碍；科研简历上"复现并验证 XXX，达到论文 xx% 精度"极具说服力
教程链接 • 《动手学深度学习》7.6节 ResNet 逐行实现（先照着打，再脱离书重写）：https://zh.d2l.ai/chapter_convolutional-modern/resnet.html
• timm 库（PyTorch Image Models，37,173 stars，最后推送 2026-09-27，官方实现对照学习）：https://github.com/huggingface/pytorch-image-models
• Papers with Code（按任务找"有代码的论文"与官方实现排行榜，复现选它）：https://paperswithcode.com/
• labml.ai Annotated Paper Implementations（逐行注释的论文实现，含 ViT/ResNet，适合对照复盘）：https://nn.labml.ai/
验收标准 复现精度与论文差距 < 2~3 个百分点；写一份 2~3 页的复现报告（含超参、训练曲线、踩坑记录）——这份报告可直接转化为组会汇报素材

项目10：跑通导师方向的 SOTA 开源项目（"读→跑→改"三部曲）

维度 内容
项目内容 从导师指定的论文出发：①精读论文→②找到并跑通其官方 GitHub（或 Papers with Code 上的高星复现）→③改一个小模块（换 backbone/换损失函数/加数据增强），观察指标变化
使用的工具 视具体方向（检测：Ultralytics/mmdetection；分割：mmsegmentation；分类与通用：timm；多模态：CLIP/open_clip）
数据集 论文所用 benchmark（通常官方 repo README 给出下载脚本）
预计耗时 3~6 周（这是三档项目中耗时上限，也是最接近真实科研的）
学习价值 "改一处、看指标"就是最小可用的科研实验；为后面第一个自己的 idea（毕设或小论文）铺垫 baseline；跑通过程中熟悉 Linux/conda/CUDA/环境管理——研究生必备工程技能
教程链接 • mmdetection（OpenMMLab 检测工具箱，32,960 stars，最后推送 2024-08-21，中文文档在 https://mmdetection.readthedocs.io ）：https://github.com/open-mmlab/mmdetection
• Ultralytics（工程化程度较高的检测框架，62,058 stars，最后推送 2026-09-28）：https://github.com/ultralytics/ultralytics
• open_clip（CLIP 开源实现，14,171 stars，最后推送 2026-09-25）：https://github.com/mlfoundations/open_clip
验收标准 成功跑通官方训练+评测；完成至少一次"自己改动→指标变化→能解释为什么"的实验

四、全景路线图（一览表）

时间 阶段 内容
