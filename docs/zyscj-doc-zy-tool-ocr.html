🔗OCR文字图片识别

来源：https://zyscj.com/zy/tool/ocr.html · 抓取时间：2026-11-01 · 外链 19 个

OCR是什么 ？ OCR （Optical Character Recognition，光学字符识别）是指电子设备检查纸上打印的字符，通过检测暗、亮的模式确定其形状，然后用字符识别方法将形状翻译成计算机文字的过程。

在线识别

  • 可以直接使用电脑版QQ的截图识别功能。
  • 发送图片至微信/企业微信，可自动识别文字
  • 目前各个品牌的手机相册长按基本都有识别文字的功能
腾讯OCR 支持多种识别方式、包括手写、身份证、表格、票据等，另外可以直接使用电脑版QQ的截图识别功能，非常方便。
阿里OCR 阿里达摩院读光OCR，识别效率高，在线识别。
百度OCR 百度官方的识别接口，质量也很不错，最大支持2M图片上传识别。
白描OCR 白描APP网页版识别工具
易飞文字识别 目前网页版免费使用，效果不错
pearocr https://pearocr.com/
yandexOCR https://translate.yandex.com/ocr
OCR Space https://ocr.space/
Onlineocr https://www.onlineocr.net/

电脑端

PandaOCR 多功能OCR识别+翻译+朗读+弹窗【开源】
天若ocr （WIN ）强大的文字识别工具，免费接口为作者提供秘钥信息，有次数限制，稳定性不保证。付费接口需自己更换，每次使用额外付费，除此之外还支持截图功能、录制gif、表格识别和公式识别等。
eSearch https://github.com/xushengfeng/eSearch
Abbyy 老牌专业的OCR识别和PDF转换工具，十分强大，pojie版可以参考

手机APP

白描 使用的是百度的OCR接口，中文识别相比之下效果最好
扫描全能王 扫描纸张为PDF非常方便，带OCR识别功能
Textgrabber ABBYY公司出品的，识别效果不错，英文识别更好
