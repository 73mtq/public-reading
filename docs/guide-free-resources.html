免费资源与算力清单

  • 适用对象：CV 方向的研究生新生，需要一个不花钱就能开跑的环境组合。
  • 复核日期：2026-09-28（星标数、免费额度与定价）。
  • 推进顺序：先注册哪些、什么时候用上，见 《起步路线》。

来源：free-for.dev 官方仓库 README（ripienaar/free-for-dev，2026-09-28 读得 138,744 stars，最后推送 2026-09-27），加上各官方定价页与文档逐一核对。第九节列出每个地址的复核结果，未能回源的条目已标明。

等级 含义 处理方式
甲级 直接读取官方接口或官方页面正文取得的数值 直接写入，标注读取日期
乙级 从官方文档、FAQ 或仓库 README 读到，本次未重复核对 写入并注明未重复核对
丙级 社区汇总、第三方博客、二手转述 只写方向性结论，注明「社区反馈」
丁级 本次没有可靠来源（域名解析失败、请求被拒、正文未读取） 保留原数值，注明未核实

优先级定义：必用 = 入学第一周就注册；推荐 = 入门 2–4 周内用上；可选 = 按需启用。

一、免费算力与 Notebook 环境（CV 实验的生命线）

资源 免费额度（2026-09 复核） CV 新生使用场景 优先级
Google Colab 免费 Jupyter 环境 + 免费 T4 GPU（16GB 显存）；资源不保证、限额动态浮动；会话最长 12 小时，空闲即断；免费运行时禁止 SSH/远程控制等 跑通第一个 PyTorch/CNN 实验、复现论文代码、导师指定论文的官方开源代码试跑；配合 Google Drive 持久化数据 ★必用
Kaggle Notebooks CPU：4 核 + 30GB RAM，无每周上限；手机验证后可开 P100×1 或 T4×2，每周 30 GPU 小时；身份验证后 TPU v3-8（96 核 330GB）每周 20 小时；单会话 12h（TPU 9h），20GB 自动保存空间 算力主力：每周 30h GPU 足够跑 ResNet/YOLO 级别的入门训练；30 万+ 公开数据集直接挂载，无需下载 ★必用
Lightning AI 免费层：1 个 Studio 24/7 常驻（每 4h 需重启）、32 核 CPU、50GB 持久存储、新用户启动额度折合约 75 小时 T4（官方口径"up to 80 free GPU hours"，A100-40G 约折 10h）；无限后台执行 云端常驻开发环境（SSH/本地 IDE 可连），PyTorch Lightning 作者出品，做持久化实验环境比 Colab 更稳；另注意其与 Ultralytics（YOLO 官方）已整合，Ultralytics 侧提供工作邮箱 $25 免费额度（一键标注/训练/部署 YOLO） 推荐
百度飞桨 AI Studio 每日登录送 8 点算力（社区反馈约合 8 小时 V100/天），社区项目可申请更多 国内访问快、无需科学上网的备选算力；中文文档友好；适合跑飞桨系教程与入门比赛 推荐（国内）
Modal 每月 $30 免费额度（部分账号 $5），serverless GPU 按秒计费 进阶：写 Python 函数即上云跑 GPU，适合自动化实验流水线；有一定工程门槛 可选
Camber（学生包） 学生免费：每月 40 CPU 小时 + 5 GPU 小时 + 50GB 存储 + 50 条 Agent 消息 AI 数据科学代理平台，GPU 时长少，作为补充算力 可选
Azure for Students $100 额度 / 12 个月，无需信用卡；⚠️ 2025 年起学生身份审核明显趋严（部分地区新申请受阻，社区有"无权访问"反馈），中国高校学生认证通过率不稳定 需要更强算力时的兜底（可开 NC 系列GPU）；建议先注册 GitHub 学生包再关联尝试 可选

关键事实（易踩坑）： - Colab 的 "Colab Pro for Education" 档位面向特定美国高校的师生，中国学生不必寻找这个入口（来源：Colab 官方 FAQ）。 - Colab 免费层对"重度/自动化/挖矿/远程控制"等行为限流，GPU 可用性随时段波动，重要实验前先把代码在 CPU 上调通再用 GPU。 - Kaggle 的 30h/周 GPU 需在账号设置中完成手机号验证；TPU 需证件级身份验证。两者独立计数，可同时拥有（即理论上每周 30h GPU + 20h TPU）。

Deepnote 免费层：无限个人项目 + 无限基础机器（2 vCPU / 5GB RAM）；学生包送 Team 计划（多人协作） 实时协作 Notebook，和同学/师兄远程结对调试、汇报演示比本地 Jupyter 直观 可选

三、数据与标注（CV 特色环节：数据集就是实验的原料）

资源 免费额度（2026-09 复核） CV 新生使用场景 优先级
Kaggle Datasets 免费浏览/下载/在线分析，公开数据集 30 万+ 找入门练手数据（MNIST/COCO 子集/各类比赛数据），Notebook 内一键挂载 ★必用
Hugging Face Hub 公开模型/数据集/Spaces 无限托管；免费 CPU Spaces（48h 不活动自动休眠）；免费账户每月附少量推理额度（约 $0.1 量级，PRO 为 $2/月） 下载预训练权重（ViT/CLIP/SD 系列）、托管训练 demo、数据集版本管理；transformers/diffusers 生态入口 ★必用
Roboflow（Public 计划） 免费、无需信用卡：15 credits/月、2 用户、单数据集上限 25 万张图、3x 数据增强；⚠️ 所有项目必须公开到 Roboflow Universe 图片标注（AI 辅助）、格式转换（YOLO/COCO/VOC 互转）、小目标检测数据集管理、在 Universe 学别人的公开项目；涉及未公开数据/导师课题勿用 推荐
Label Studio 开源（Apache-2.0），自托管完全免费且无配额；支持检测框、多边形分割、关键点、视频追踪 需要私有/大量标注时本地部署；配合 CVAT 类工具构成实验室标注流水线 推荐
CVAT 开源（MIT），自托管免费，工业界标准标注工具之一 课题组级标注管理；入门阶段可先了解 可选
国内备选：启智 OpenI / 九天·毕昇 免费算力券与免费 GPU 环境（社区汇总信息） 国内补充算力，支持国产框架（昇思 MindSpore） 可选（国内）

关键事实： - Roboflow 2025 年改为 credits 计费后免费额度明显缩水（免费层 15 credits/月，社区有涨价抱怨），适合轻量课程作业，重标注任务请自托管 Label Studio/CVAT。 - CV 新生第一个自建数据集建议流程：Roboflow Universe 找类似公开项目 fork 学习 → 小规模练手用 Roboflow Public → 涉及私有数据切 Label Studio 本地部署。

四、模型平台与 AI 服务（写代码之外的第二引擎）

资源 免费额度（2026-09 复核） CV 新生使用场景 优先级
Google AI Studio 免费使用 Gemini 系列模型（网页端 + API 免费层）。具体配额以官方限额页实时数值为准：https://ai.google.dev/gemini-api/docs/rate-limits 读论文时贴截图问公式/图表、生成代码骨架、把英文论文的文字转成讲解；比 ChatGPT 免费版上下文更长 推荐
OpenRouter（:free 模型） 免费 API 聚合：:free 后缀模型 20 请求/分、50 请求/日（未充值账户；历史充值 ≥$10 后升至 1000 请求/日） 一个 Key 调用数十家免费模型（含视觉模型），写自动化脚本/批量处理时的免费 LLM API；新号每日 50 次够轻度使用 推荐
Hugging Face Inference API 免费账户每月少量推理额度（配合 HF 生态） 快速验证开源 CV 模型效果，不部署直接 API 调用 可选

⚠️ 与《AI 使用边界》的衔接： 以上生成式 AI 工具用于"解释术语、检验理解、debug"属于提效；用于"代读论文、代写汇报"则触碰认知负债红线，具体规则见 《AI 使用边界》。

七、风险与注意事项

  1. 免费额度随时间变动：本清单的数字复核于 2026-09-28，Roboflow 与 Netlify 都已发生过计费方式变更，注册前再看一眼定价页；
  2. 隐私红线：Roboflow Public 计划强制公开项目；导师课题/未发表数据一律走自托管（Label Studio/CVAT）；
  3. 平台条款：Colab 免费层禁止长时间后台挂机、SSH 隧道等行为，违规会触发限流甚至封号；
  4. 国内访问：Colab/Kaggle/HF/Lightning 均需科学上网；百度飞桨 AI Studio / 启智 OpenI 为国内无门槛替代；
  5. 学生认证：Azure 学生 $100 审核趋严（2025 社区反馈），申请失败别恋战，转 GitHub Pack 路径。
